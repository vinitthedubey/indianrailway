
# Indian Railways

It is "Empowering transportation stations with seamless, multilingual communication capabilities to
enhance accessibility and inclusivity for passengers and customers. Our vision is to create a dynamic
information ecosystem that transcends linguistic barriers, providing timely and accurate information
in Indian languages and foreign languages for tourists. By leveraging cutting-edge technology and
user-centric design, we aspire to revolutionize the way information is delivered and accessed at
stations, fostering a more connected and informed travel experience for all."


## Installation

In command line interface follow below steps

Step 1: git clone https://github.com/vinitthedubey/indianrailway.git

Step 2: pip install -r requirements.txt

Step3: pip app.py
